MIGIUDE プライバシーポリシー

最終更新日：2026年10月12日

1. 対象

MIGIUDE（以下「本アプリ」）は、開発者本人が個人的に利用する AI 秘書です。本アプリが扱うのは開発者本人の Google アカウントのデータのみで、第三者のアカウントには提供していません。

2. 取得する情報

  • Gmail（読み取り専用：gmail.readonly）：メールの差出人・件名・本文などの内容
  • Google カレンダー（calendar）：予定の名前・日時・場所などの内容

3. 利用目的

取得した情報は、開発者本人への次の機能の提供にのみ利用します。

  • 朝のブリーフィング（その日の予定と重要なメールの要約）
  • 予定の前のリマインド
  • 重要なメールの通知
  • 本人の指示による予定の登録・変更

本アプリはメールの送信・削除・変更を行いません。

4. 保存と管理

Google の認証情報は、開発者本人の PC 上に暗号化して保存します。本アプリが独自のサーバーにメールや予定のデータを保存・蓄積することはありません。要約や通知の作成のため、必要な範囲の内容が AI モデルの提供元（OpenAI）に送信されます。

5. 第三者への提供

上記 4. の処理を除き、取得した情報を第三者に提供・販売・共有しません。広告目的には利用しません。

6. Google API サービスのユーザーデータに関するポリシーの遵守

本アプリによる Google API から受け取った情報の使用および他のアプリへの転送は、Google API サービスのユーザーデータに関するポリシー（限定使用の要件を含む）に準拠します。

MIGIUDE's use and transfer to any other app of information received from Google APIs will adhere to the Google API Services User Data Policy, including the Limited Use requirements.

7. アクセスの取り消し

本アプリへのアクセス許可は、Google アカウントの「サードパーティ製のアプリとサービス」からいつでも取り消せます。
